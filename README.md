One funny line a smart fridge texts its owner at 3am, written by a small
Node program. The program writes the line to `entry.txt` in the output
directory, where the make.fun grader reads it:

> It's 3am and you've opened me four times for nothing — at this point I'm not a fridge, I'm your emotional support appliance.

The joke is a reframe: after four empty 3am openings, the fridge stops
being a fridge and becomes an emotional support appliance. No milk, no
ice, no door left open — the joke is the owner's 3am habit, not the
contents.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```
